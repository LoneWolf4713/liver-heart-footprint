# validation_v2 notes (session 2026-10-01)
## Decisions / findings (chronological)
1. CoFID "1.1 Notes" sheet does NOT explain the reference column. Analysed vs recipe-calculated distinguished from the *Description* (col C) + *Main data references* (col F) of each row: analysed rows say "N samples" and cite a lab report (University of Leeds 2007; Aspland & James 1997; LGC; Direct Laboratories); recipe rows say "Recipe ..." with reference "Updated 2014" and are EXCLUDED as ground truth (they are calculations, not measurements). ground_truth.csv keeps only the analysed rows with the evidence string.
2. Chen, Gilbert & Khokhar 2009 (zenodo 10043766): record is "Restricted" - full text not accessible; only the abstract is. Source C = NOT AVAILABLE. (Abstract says calculated values "exceeded those found by analysis" for most nutrients, differences smallest for protein/fat/carb - noted as context, not as a data point.)
3. safefood 2015: Table 5/6 per-portion means + Table 3 average portion weight. per-100g = mean fat / mean portion weight. Caveat: mean-of-portion / mean-of-weight is not the mean of per-sample ratios.  No water or carbohydrate given -> only M2 (fat % energy) and M3 usable.
4. INDB repo: INDB.xlsx = 1,014 COOKED RECIPES (not raw ingredients) and has no water column. The IFCT raw-ingredient table is NOT in the repo (README: must be requested from NIN). UK_fct.xlsx (144 ingredients) and US_fct.xlsx (54) are only the extras. So the handoff's "INDB per-ingredient mapping" is infeasible for most Indian ingredients.
   -> Fallback allowed by the handoff: UK CoFID raw-ingredient rows (full CoFID_2021.xlsx, has water, fat, protein, carb, fibre, kcal). All ingredient nutrition therefore comes from CoFID 2021 (cite food code). USDA FDC only if CoFID lacks the item (cite FDC id).  This is a deviation from "INDB first"; ingredient data is UK-lab data, not IFCT (limitation: Indian varieties of okra/methi/etc may differ).
5. Recipes fetched with requests (>=1.1 s gap, robots.txt checked). Sites outside the handoff list (khinskitchen, krumpli, kennymcgovern, motionsandemotions, vegrecipesofindia) were used for prawn bhuna / coverage, found via Stealth Search; robots allowed.
6. Rejected recipes (title mismatch): pipingpotcurry "Chicken Tikka Masala Pasta"; indianhealthyrecipes "Coconut Milk Pulao" (not vegetable pilau); pipingpotcurry "Shrimp Masala" (not a bhuna). 404/robots/no-JSON-LD URLs are in fetch_log.csv.
7. Parsing: all 549 raw lines parsed by the model into parsed_lines.txt (key, qty min/max, unit, status); grams computed deterministically in compute.py. First run flagged R03/R05 for "100 g" - these were 2 tomatoes x 50 g (Units.xlsx rule), not defaults; test refined to flag only lines without an explicit rule. R05's oil was only in the method text (3 tbsp) and was added as a documented line.
8. Excluded: R27 (curry broth base sauce), 3 title-mismatch recipes, Chen 2009 (restricted), CoFID chicken balti (retail, not needed), safefood pilau rice and naan (no matching home-style recipes fetched).
